ATLAS TRAINING PRO • TUTORIAL OFICIAL DO SEU PACOTE

Seu ATLAS no iPhone 14. Grátis.

Instalação na tela inicial, uso sem senha, registros locais e opção de backup automático na nuvem. Você não precisa publicar o app na App Store nem pagar Apple Developer.

Criar repositório GitHubConfigurar nuvem (opcional)

1. Publique gratuitamente no GitHub Pages

1

No computador, descompacte ATLAS_Training_Mobile_PWA.zip. A pasta contém index.html, ícones, manifest.webmanifest e service-worker.js.

2

Entre no github.com, crie uma conta gratuita e depois abra Novo repositório.

3

Defina o nome do repositório, por exemplo atlas-training, selecione Public (necessário no plano GitHub Free para Pages) e clique em Create repository.

4

No repositório, escolha Add file → Upload files. Envie os arquivos da pasta, incluindo o index.html na raiz, e clique em Commit changes. Não envie nenhum backup de treino ou dados de alunos para o GitHub.

5

Abra Settings → Pages, escolha Deploy from a branch, selecione main e /(root), e clique em Save. Quando a publicação estiver pronta, aparecerá o endereço do site.

O endereço geralmente segue este formato: https://SEU-USUARIO.github.io/atlas-training/. Substitua pelo seu usuário e nome de repositório; use o link exibido pelo GitHub.

2. Coloque o app na Tela de Início do iPhone

1

No iPhone 14, abra Safari, não o navegador dentro do WhatsApp/Instagram. Digite o endereço HTTPS do seu ATLAS publicado no GitHub Pages.

2

Toque no ícone de Compartilhar do Safari (quadrado com seta apontando para cima). Em versões do iOS, talvez precise abrir primeiro o menu da página.

3

Procure Adicionar à Tela de Início. Ative Abrir como App (caso apareça) e toque em Adicionar.

4

Pronto: um ícone do mascote ATLAS aparecerá na Tela de Início. Abra-o, digite apenas seu nome e siga o tutorial inicial.

O app é um PWA, não um aplicativo publicado na App Store. Ele funciona offline depois de carregado, mas não desinstale/limpe os dados sem fazer backup: o armazenamento local pode ser removido pelo iOS ou pelo usuário.

3. Proteja seus dados imediatamente, sem pagar

Backup manual para iCloud Drive

1

Dentro do ATLAS, abra Mais → Configurações → Salvar em Arquivos / iCloud Drive.

2

No menu de compartilhamento do iPhone, escolha Salvar em Arquivos, selecione iCloud Drive e confirme.

3

Para restaurar no futuro, use Configurações → Restaurar backup JSON e escolha o arquivo guardado no app Arquivos.

Esta etapa é manual. O salvamento automático dentro do app não equivale a backup externo — para ter recuperação em outro celular sem exportar arquivos, configure a etapa 4.

4. Backup automático na nuvem com Supabase Free

Opcional, mas recomendado se você quer recuperar os registros em outro aparelho mesmo após perdê-lo. O acesso normal ao ATLAS continua só com nome; a nuvem pede código por e-mail uma vez em cada dispositivo.

1

Crie uma conta em supabase.com/dashboard. Crie um projeto no plano gratuito, com um nome como atlas-backup e guarde a senha administrativa do projeto em local seguro (ela nunca entra no ATLAS).

2

Na área SQL Editor do projeto, abra o arquivo SUPABASE_BACKUP_SEGURO.sql do pacote, copie todo o conteúdo, cole no editor e execute com Run. Esse script cria uma tabela privada com Row Level Security (RLS) para cada usuário ver somente o próprio backup.

3

Em Authentication → Email Templates → Magic Link (a localização pode variar no painel), configure o corpo do e-mail para mostrar o código {{ .Token }}, por exemplo: Seu código ATLAS: {{ .Token }}. Assim o serviço envia um código em vez de um link.

4

No Supabase, procure a Project URL e a chave pública anon/publishable em Project Settings → API / API Keys. Use somente a chave pública; nunca copie a service_role ou uma secret key.

5

No ATLAS do iPhone, entre em Mais → Configurações → Nuvem protegida por e-mail. Cole a URL e a chave pública, toque em Salvar configuração.

6

Digite seu e-mail, toque em Enviar código, copie o código recebido e selecione Conectar nuvem.

7

Toque em Enviar meus dados para o primeiro backup. Depois disso, novos registros são enviados automaticamente quando houver internet e o status confirmar Backup na nuvem.

8

Quando trocar de iPhone: instale o ATLAS pelo mesmo endereço, entre com seu nome, configure o mesmo Supabase, confirme o mesmo e-mail por código e use Restaurar da nuvem. Antes de restaurar, não comece novos treinos no aparelho vazio para evitar conflitos.

Se aparecer “Não sincronizado”, os dados continuam no aparelho, mas não estão protegidos na nuvem. Confira conexão, serviço e permissões de acesso. O plano Free tem limites e disponibilidade sujeitos às condições do Supabase.

5. Teste que realmente funciona

  1. Crie um treino ou cadastre um aluno de teste e feche o ATLAS.
  2. Abra o ícone novamente e confira se o registro permanece.
  3. Ative a nuvem, envie os dados e confirme o status de sucesso.
  4. Faça um backup manual em iCloud Drive também.
  5. Se possível, teste a restauração em outro navegador ou aparelho, antes de depender do backup.

O código do aplicativo fica público no GitHub Pages, mas seus dados de treino não vão para o repositório: são salvos localmente e, se você configurar, no Supabase protegido. Não envie dados de saúde ou informações confidenciais de alunos sem autorização e medidas adequadas de privacidade.
